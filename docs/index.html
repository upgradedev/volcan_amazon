Volcan: Accessible Voice and Braille AI Agent Forge

Volcan turns a code patch into a spoken digest, an audio earcon and a Unicode Braille stream, so a blind or mobility-impaired developer can review an AI agent's work without reading a diff.

  • MCP server, revision 2025-11-25
  • Streamable HTTP transport
  • Unicode Braille U+2800
  • Pure-Python PCM earcons

Silent tactile Braille terminal

For quiet hours, open offices and deafblind developers, Volcan renders patches and commands as Unicode Braille patterns (U+2800 to U+28FF) that a refreshable Braille display can present without any sound.

Keyboard map

Every control on this page is a real button in the tab order. There are no click-only elements, and no action requires a pointer.
KeyWhat it does
Tab / Shift+TabMove forward or back through every control, in reading order.
Enter or SpaceActivate the focused button.
Tab from the topReveals Skip to main content, which jumps past the header.
Alt+1Move focus to the spoken command box.
Alt+2Move focus to the unified patch box.
Alt+3Move focus to the Braille cell stream, which is scrollable by keyboard.
EscapeStop speech that is currently playing.

Results are announced by screen readers through aria-live regions: digests and lease state politely, security findings assertively.

The MCP surface of this project lives at POST /mcp and GET /mcp. To check it yourself, run python -m src.interfaces.mcp_server and then python scripts/mcp_conformance.py.
