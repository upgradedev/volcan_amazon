By voice or by keyboard

          
Talk through a real pull request, then request changes

          

            Open a public pull request, ask what changed, hear the exact lines, spell one out
            symbol by symbol. Every turn posts to POST /api/review/turn and reads back
            what it understood before it acts. The review write is dry-run by default: the server
            re-reads the head commit, records the exact request it would send, and sends nothing
            unless it runs with VOLCAN_GITHUB_WRITE=1 and a token.

Model Context Protocol, handshaken in your browser

            

              Volcan's MCP server is written by hand against revision 2025-11-25 over the
              Streamable HTTP transport, with no MCP SDK. This button performs a real
              initialize, a real notifications/initialized and a real
              tools/list against POST /mcp, then prints what came
              back: whether the endpoint chose a stateful identifier or stateless mode, and the
              JSON Schema of every tool exactly as the server published it. The public Lambda is
              transport-stateless, so request-contained calls need no process-specific MCP id.
              Dialogue and pending approval state remain process-local and are not durable across
              Lambda environments. Check it independently with
              python scripts/mcp_conformance.py http://127.0.0.1:8000/mcp.

Governed action: staged, leased, never executed

            

              A high-consequence command is bound by HMAC-SHA256 to its own payload hash and to
              a lease. Volcan plans the command and does not run it. The countdown below is
              computed from the expires_at_epoch the server returned, not from a
              timer this page invented.

One press, one real round trip

            
Hear this code review calls the live digest and Braille endpoints,
              plays the returned WAV and reports this browser's measured round trip. No result is
              prewritten into the page, and there is no second implementation of the product in the
              browser to fall back on.

            
The earcon

            
Volcan sends a rising three-note cue, DIFF_READY, when a digest is ready,
              and a falling two-note cue, SECURITY_FINDING, when the patch touches
              security, so the verdict arrives before the sentence does. The waveform on the stage is
              drawn from the 16-bit PCM samples of the WAV the server returned, and the contour beside
              it is measured from those same samples by counting zero crossings in each note. The two
              cues are different audio: switch between the first and the fourth patch and the
              waveform, the contour and the caption all change with the bytes.

            
Audio plays through your speakers. Replay the cue plays it
              again, and every cue also carries a written description from the server in the same
              live region.

            
The spoken sentence

            
Words brighten as the browser's speech engine reports reaching them. When the engine
              reports no word positions, the whole sentence brightens when speech starts; when it has
              no voice at all, the sentence is shown in full at once. No word timing is invented.

            
The Braille

            
Volcan renders the patch as Unicode Braille in the U+2800 block for a refreshable
              display. The default is eight-dot code fidelity, one cell per printable character, so
              (, ) and = keep their own cells; six-dot literary
              Braille is lossy for code, and the server names what it lost in this patch. The large
              cells on the stage are the server's own code points drawn dot by dot, and the cells
              that differ between the removed and the added line are marked.

            
The three numbers

            
Synthesis engine is read from the synthesis_mode field of
              the response, with synthesis_fallback_reason printed when no model answered.
              Round trip is wall clock across fetch and the JSON parse,
              from performance.now(). Change size is counted by the
              server's unified diff parser, not by this page.
