Governed action: staged, leased, never executed

A high-consequence command is bound by HMAC-SHA256 to its own payload hash and to a lease. Volcan plans the command and does not run it. The countdown below is computed from the expires_at_epoch the server returned, not from a timer this page invented.

Keyboard map and the accessibility contract

This page is the product's shop window, so it holds itself to the standard the product argues for. tests/e2e/test_html_structure.py fails the build when any promise below stops being true of this file.

Every action here is a real button in the tab order. Nothing needs a pointer.
KeyWhat it does
Tab and Shift+TabMove through every control in reading order.
Enter or SpaceActivate the focused button.
Tab from the topReveals Skip to main content.
Alt+1Focus the primary action, Hear this code review.
Alt+2Focus the patch box.
Alt+3Focus the Braille cell region, which scrolls by keyboard.
EscapeStop the speech and stop the earcon.
  • Every audio cue carries a written description in the same live region.
  • Async results are announced through aria-live, security findings through role="alert".
  • The focus ring is a 3px outline offset from the control, in both colour schemes.
  • prefers-reduced-motion removes every animation and the smooth scroll.
  • Light and dark follow prefers-color-scheme, and neither is an afterthought.
  • An empty panel says why it is empty and which control fills it.
